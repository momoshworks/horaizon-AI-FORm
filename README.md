## 🌌 Overview | نظرة عامة

منصة **Horizon AI Registration System** هي واجهة ويب متطورة مصممة لاستقبال وفرز طلبات الانضمام للأنشطة والمسارات التقنية الخاصة بفرق الذكاء الاصطناعي. تمتاز بتجربة مستخدم خيال علمي (Sci-Fi / Cyberpunk Theme)، تأثيرات جزيئات متحركة في الخلفية (Canvas Particles)، ونظام إدارة مدمج بالكامل للمنظمين (Built-in Admin Panel).

---

## ✨ Key Features | المميزات الأساسية

### 🎨 تجربة المستخدم (User Experience)
- **Cyberpunk / Futuristic UI:** خطوط نيون (Orbitron & Cairo)، تدرجات لونية داكنة، وإطارات مشعة (Glow Effects).
- **Interactive Particle Background:** خلفية جزيئات متحركة تفاعلية تتجاوب مع الحركة.
- **Client-side Form Validation:** التحقق الفوري والدقيق من صحة البيانات (الاسم، البريد الإلكتروني، رقم الهاتف، والمسار المختار).

### 🛠 لوحة الإدارة المتطورة (Built-in Admin Dashboard)
- **Password-Protected Access:** نافذة محمية بكلمة سر للوصول إلى بيانات المسجلين.
- **Real-time Counter Badge:** عداد فوري لعدد المشتركين المسجلين.
- **Data Exporting:** تصدير سجلات المسجلين بصيغتي **CSV** و **JSON** بضغطة زر.
- **Google Sheets Cloud Sync:** ربط مباشر عبر Webhook لتسجيل كل طلب تلقائياً في جداول بيانات Google دون الحاجة لسيرفر خارجي.
- **Data Persistence:** حفظ البيانات محلياً عبر `localStorage` لضمان عدم ضياع أي طلب أثناء انقطاع الاتصال.

---

## 🛠 Tech Stack | التقنيات المستخدمة

- **Frontend:** Semantic HTML5, CSS3 Custom Properties (Variables), Responsive Flexbox & Grid.
- **Scripting:** Pure Vanilla JavaScript (ES6+ Async/Await, Fetch API).
- **Integrations:** Google Apps Script Webhooks (Google Sheets API).
- **Typography:** Google Fonts (`Orbitron` & `Cairo`).

## 🚀 How to Run | طريقة التشغيل

### التشغيل الفوري:
المشروع عبارة عن Single Page Application (SPA) لا يحتاج أي تثبيت! افتح ملف `index.html` في متصفحك مباشرة.

### النشر على GitHub Pages:
1. توجّه إلى إعدادات المستودع (Settings) -> **Pages**.
2. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
3. سيكون الرابط المباشر متاحاً للعالم في ثوانٍ.
